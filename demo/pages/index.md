# Podcast theme demo

This site demonstrates the [_Podcast_ component theme](https://github.com/Cecilapp/theme-podcast) for [Cecil](https://cecil.app):

1. an **RSS feed** for the `episodes` section, compatible with Apple Podcasts and Google Podcasts, with a **style sheet** to display it nicely in a browser: [open the feed](episodes/rss.xml)
2. an **HTML audio player** that resumes playback where you left off, and supports media keys and lock screen controls (seek, previous and next episode)
